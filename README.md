### About

I'm a software engineer at **vSingh CPA LLC**, working remotely with a U.S. team on **BOSS** &mdash; a
multi-tenant ERP for government contractors built around DCAA compliance.

- I work across the whole stack: React interfaces, Next.js API routes, PostgreSQL schema design, and
  event-driven background jobs.
- Recent work there: a federal incurred-cost reporting engine, a regulated timekeeping and approval
  workflow, an email-to-receipt expense pipeline with OCR, and payment/banking integrations.
- I care about **testing and correctness** &mdash; Vitest, React Testing Library, and Playwright
  end-to-end suites &mdash; in a domain where an audit trail has to be right.
- Most of that work lives in a **private organization repository**, so the public repos below are only
  part of the picture.
- Outside work I've built a video streaming platform, an e-commerce API, and a blockchain-based voting
  system in Solidity.

**Open to full-stack and frontend engineering roles &mdash; remote.** Reach me at
**abhay473165@gmail.com**.
